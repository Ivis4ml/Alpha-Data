# v3 识别与统计功效框架：实现与首轮结果

日期：2026-07-16。对应研究规范 `research/Polymarket_中国期货预测_识别与统计功效_v3.pdf`
（下称"框架"）。代码：`alpha_data/polymarket/v3/` 与 `scripts/v3_*.py`；
测试：`tests/test_v3_framework.py`（19 项，全部通过）。

本文回答两个问题：

1. 框架在本仓库数据现实下能实现到什么程度（第 1-3 节）；
2. 相对已提交的 v1.1 管道（`docs/cn_futures_polymarket_report.md`），
   新框架是否带来可度量的提升（第 4-6 节）。

## 0. 结论摘要

1. **框架已完整实施**（在无订单簿数据源的约束下的最大可实现子集），全管道
   一键复现（第 7 节），19 项单元测试通过，数据隔离协议全程执行。
2. **样本扩展是自爬数据的第一项直接收获**：重叠窗口 75 -> 127 个交易日
   （+70%），登记市场 389 -> 492；链上 `ConditionResolution` 补爬把结算时刻
   覆盖从作者元数据的 56/425 提升到 455/492，使 Power Gate 的 surprise 样本
   从 79 增至 278 个。
3. **Layer 4 首次部分可识别**：mideast_conflict 与 russia_ukraine 对 SC / AU
   的四个组合通过功效门控；mideast 的 category 影响系数在训练窗内
   beta = 0.060（SC）/ 0.044（AU），t > 4——一个满 surprise（意外事件发生）
   对应次一交易日约 6% / 4.4% 的收益，量级与 2 月底冲突升级时的实际走势
   一致。其余十个组合按预注册规则降级 sign-only。
4. **多类别组合降噪有可度量的改善但没有翻转结论**：同维度对比下，v3 信号
   （滤波 + 族投影 + 公共因子正交化）在 8 个品种中 6 个的 OOS 增量 R^2 优于
   v1.1 基线；豆粕 M 从 +3.2% 提高到 +5.4%（Clark-West t 约 2.0，全表唯一
   稳定为正的品种）。但**两套信号对次日方向的 OOS 增量预测力整体仍不为正**。
5. **结构性结论与 v1.1 一致且现在有识别力支撑**：Polymarket 的信息价值集中
   在国内闭市时段的**同期吸收**通道（扩展样本 corr 0.39-0.74；mideast×SC
   控制 USO 后 HAC t = 4.9，样本翻倍后增强），而不在隔日预测通道。框架的
   贡献是把"预测力≈0"从小样本猜测变成带功效核算与嵌套检验的正式结论，
   同时把可识别的部分（吸收、mideast 事件影响、tension-波动关联）从噪声中
   分离出来。

## 1. 样本扩展：自爬链上数据把重叠窗口延长 70%

v1.1 的首要局限是样本（75 个重叠交易日、被单一地缘事件主导）。本轮用自爬
链上成交（`docs/POLYMARKET_CRAWL.md` 的爬虫）把 tape 延至 2026-07-14，与期货
库（至 07-13）的重叠达到 **127 个交易日**：

- **统一 tape**（`alpha_data/polymarket/v3/tape.py`）：HF `daily_aligned`
  （至 04-28 区块 86,126,998）+ 自爬日分区（自区块 86,127,000），按区块号
  天然衔接，扩展段构造规则与公开数据集逐条对齐（去中继腿、只留已核验场馆、
  剔除 negRisk、二元市场、同一 `p_event` / `D` 真值表）。
- **迁移期同质性实测**：v2 交易所 2026-04-03 上线至 04-28 切换期间，抽样六个
  3,000 块窗口的 v2 成交为 6 / 0 / 37 / 56 / 108 / 157 条，对应 v1 为 42 万至
  74 万条（v2 占比 < 0.04%）。HF 段缺 v2 不构成流量断层。
- **`resolved_at` 补齐**：HF 数据集的 `resolved_at` 元数据本身稀疏（登记市场
  仅 56/425 有值），补爬链上 `ConditionResolution` 事件两段——扩展期
  （区块 86,127,000 以后，880,309 行）与 2025-12 至 2026-04（区块 80,600,000
  起，790,799 行），区块时间由成交事件的 (区块, 时间) 对 ASOF 回填（误差
  秒级）。登记市场的结算时刻覆盖从 170/492 提高到 **455/492**（其余 37 个
  尚未结算）。
- **登记表**：同一套事前注册规则（v1.1 的 RULES 原样），窗口右端延至 07-13，
  命中 **492 个市场、836 个 (市场, 品种) 对**（v1.1：389 / 658）。扩展期新市场
  无作者派生的 `category_refined` 列，对 NULL 类别放行、只靠 slug 模式与排除词
  （已核实新增命中均为同族阶梯的新月份轮次）。

## 2. 框架各层的实现与偏离（诚实清单）

| 框架层 | 实现 | 主要偏离与理由 |
|---|---|---|
| Layer 0 point-in-time | 统一 tape + 时点化准入 `admit_ts` | 无历史订单簿与条款编辑历史（数据源不存在）；P0 双盘口机制验证不适用于成交 tape |
| Layer 1 潜在信念 | logit 局部水平 Kalman，`(q, r0)` 逐市场网格 MLE；观测噪声 `R_k = (spread_k/2)^2 + r0^2/n_k`（spread 为买卖两向中位数差换算 logit 域）；期限乘子两轮估计 | 无盘口 microprice / TW-mid，观测为 15 分钟桶两向中位数均值；漂移 `mu_c(tau)` 取 0，机械收敛靠结算截断与期限乘子处理 |
| Layer 2 校准与投影 | 族内加权等张投影（PAVA）+ raw tension | **类别校准按预注册 overlap gate 降级为不做**：地缘长期限类别 resolved 支撑不足（框架 §6.1 预判的情形），只保留 raw 轨 |
| Layer 3 事件几何 | 日期族 hazard（front 阶梯 `dLambda`）、价格阈值族分布特征（隐含中位数 / 尾部质量 / 熵）、story 聚合、平台公共因子与正交化 | 公共因子用 family 级创新的流动性加权截面均值（框架允许的稳健变体；PC1 作诊断）；正交化为展开窗口（防前视） |
| Event Gate | `families.py` 规则化标注 `event_source_type` / `layer4_eligible`；价格阈值族（oil_price / metal_price 全部）禁入 Layer 4 | 标注按 slug 结构自动化，未做人工复核轮（样本 492 个市场可控，抽查通过） |
| Power Gate | 结算 surprise（`Y - sigmoid(z_pre)`，结算前 24h 滤波状态）、聚类设计效应（family × ISO 周，rho=0.5）、80% 功效 MDE、`delta_econ = 2 sigma_daily` | 首个决定性消息时刻不可得，以结算前 24h 代理事前概率 |
| Layer 4 影响换算 | 通过组合估计 category beta（训练窗 < 2026-05-15，单次切分冻结），其余 sign-only | 样本量不支持滚动 cross-fitting（每折事件数不足），单次切分如实标注 |
| Layer 5 增量预测 | 嵌套 M0/M1/M2 展开窗口 OOS + Clark-West + HAC；控制集 = 品种直连 ETF + SPY + UUP + 自身滞后 + 平台公共因子 | 汇率用 UUP（美元指数 ETF）代理 USDCNH（无本地 FX 分钟源）；ETF 控制至 06-29（美股库右端） |

数据隔离协议（框架 §11.2）执行情况：Layer 1 参数由 Polymarket 内部预测似然
选取；期限乘子由标准化创新的 tau 分桶方差估计（PM 内部）；正交化与标准化为
展开窗口；期货收益首次出现于 Power Gate（sigma 的功效核算，框架附录 A 明确
允许）与 Layer 4 训练窗。

## 3. 测量层内部验证（Polymarket 内部，不涉期货）

图 `docs/figures/v3/f_v3_term.png`。

- **期限异方差是真实且可估计的**（框架 §5.3 得到数据支持）：标准化创新的
  方差比按剩余期限呈 U 形——[30, inf) 天 0.97、[7, 30) 天 0.79、[2, 7) 天
  0.73、[0, 2) 天 1.29。临近截止两天内方差跳升三成，即机械收敛与事件结算
  的爆发段；第二轮滤波以此曲线作 Q 乘子。
- **H1-lite（诚实的否定结果）**：滤波一步预测创新方差 / 原始桶间差分方差
  = 1.108。两向中位数桶价本身已足够干净，Kalman 滤波在一步预测上并不优于
  LOCF。滤波的实际价值在别处：给出创新的**条件方差尺度**（跨市场可比的
  标准化）、边界处的状态不确定度 P（时效判据的连续版本），以及族投影的
  平滑输入。
- **H2-lite（弱支持）**：族内单调性违反 795 处（占投影快照的约 0.1%），
  违反后下一边界价格向投影方向修复的比率 0.514——方向正确但接近随机
  （SE 约 1.8%）。解读：阶梯族的定价在 15 分钟粒度上已高度一致，
  投影更多是护栏而非信息源；tension 的截面水平低（框架 H2 在本样本
  不构成强证据）。

## 4. Power Gate 功效表：结算数据决定了哪些影响系数可识别

图 `docs/figures/v3/f_v3_power.png`，表 `v3_power_table.parquet`。

功效核算对结算记录的完整性极其敏感，这一点在本轮有直接的对照实验：只用
HF 元数据的结算时刻（56/425 覆盖）时，surprise 样本仅 79 个，**全部 14 个
（主题, 品种）组合的 MDE 超出经济上限**（mideast×SC 的 MDE 达上限十余倍），
Layer 4 整体降级。补齐链上 `ConditionResolution` 后（278 个 surprise 样本），
**四个组合通过门控**：

| 主题 × 品种 | 事件数 | 有效样本 | MDE | 上限 | 决策 |
|---|---|---|---|---|---|
| mideast_conflict × AU | 191 | 124.2 | 0.027 | 0.058 | category_beta |
| mideast_conflict × SC | 191 | 124.2 | 0.047 | 0.099 | category_beta |
| russia_ukraine × AU | 40 | 38.4 | 0.056 | 0.058 | category_beta |
| russia_ukraine × SC | 40 | 38.4 | 0.095 | 0.099 | category_beta |

其余十个组合 MDE 超限（taiwan_risk 的 surprise 变差恰为零——3 个事件全部
按事前概率实现），按预注册阶梯降级 sign-only。

方法学含义：

1. 降级阶梯不是摆设——它先在劣质结算数据下正确地全线拦截，又在数据补齐
   后精确放行了样本最厚的两个主题。若 v1.1 直接估计市场级 beta，得到的
   将是不可识别参数的噪声实现。
2. **自爬管线在此有不可替代的作用**：公开数据集不含可用的结算时刻，
   Power Gate 依赖的 `(结算时刻, 事前概率, 结果)` 三元组只能从链上事件
   重建。
3. 通过门控只意味着"可检验"：russia_ukraine 的系数最终不显著（第 6 节），
   这是功效充分下的真实阴性，与"测不出"有本质区别。

## 5. Layer 5：嵌套 OOS 增量预测（v3 vs v1.1 基线）

设计：预测目标 `r_day(t)`（当日日盘收益），信号窗 `pre = [前收盘 15:00,
当日 09:00)` 严格早于目标窗；控制集 M0 = 品种直连 ETF（USO / GLD / SLV /
CPER / SOYB / XME / ASHR）+ SPY + UUP + 自身滞后 + 平台公共因子；展开窗口
一步预测，最小训练 40 个观测，OOS 约 77-82 个交易日 / 品种。图
`docs/figures/v3/f_v3_oos.png`，表 `v3_oos_results.parquet`。

| 品种 | v1.1 基线 | v3 精简（同维度） | v3 全测量层 |
|---|---|---|---|
| AG | -17.4% | **-10.2%** | -10.7% |
| AU | -39.4% | **-23.7%** | -80.3% |
| CF | **-3.6%** | -8.0% | -5.1% |
| CU | -15.6% | **-12.7%** | -33.7% |
| I | -1.4% | **-0.8%** | -5.2% |
| IF | **-0.2%** | -0.9% | -1.4% |
| M | +3.2% | **+5.4%** * | -1.4% * |
| SC | -3.6% | **-3.1%** | -12.5% |

（OOS 增量 R^2 相对 M0；* 为 Clark-West |t| >= 1.645。）

三个可辩护的读数：

1. **绝对水平：两套信号加入强控制集后，对次日方向的 OOS 预测力整体为负。**
   唯一例外是豆粕 M（us_china_trade 主题，CW t 约 2.0）。这不是实现失误——
   同期吸收显示信息确实存在，但它在闭市窗口内已被定价，日盘开盘后无剩余。
2. **相对改善：同维度对比（v3 精简 vs 基线）下 v3 在 6/8 品种上损失更小或
   增益更大**（AU 的 OOS 损失近乎减半，M 的正增益扩大）。滤波 + 正交化确实
   降低了信号噪声——这就是"多种类组合降噪"的效果，只是降噪后剩下的
   可预测成分本身不大。
3. **全测量层变体（+hazard、+价格分布特征）普遍差于精简版**：约 120 个
   训练观测承载不起 10-14 个回归元，过参数化损失超过特征增益。hazard 与
   分布特征应作为专项检验对象而非默认并入预测面板。

样本内 HAC gamma（`v3_insample_gamma.parquet`）：us_china_trade 在 M 上为正
（t 约 +2.2）、在 CF / I 上为负（t 约 -2.6 / -2.0）——同一主题跨品种符号
不一致，按 v1.1 的标准继续列为探索性，不作方向声称。

Layer 4 的影响信号（M2）在单类别通过的品种上与测量信号共线（impact =
beta × S_orth 是标量倍数），故 M2 与 M1 拟合恒等；其价值是**经济单位的
换算**（surprise -> 收益幅度）而非额外预测力，报告如实注明。

## 6. 同期吸收复核、H4 与影响系数

**吸收（扩展样本，图 `f_v3_absorption.png`）**：v1.1 的头部结论在样本翻倍后
全部保持——oil_price×SC gap 相关 0.74（HAC t 5.0；控制同窗 USO 后 t 3.7）、
mideast×SC 0.52（t 4.0；控制后 **t 4.9**，v3 信号优于基线的 3.8）、
metal×AU 0.54、metal×AG 0.39。控制境外基准后 mideast 主题仍有独立增量，
且随样本增大而增强——这是"Polymarket 含有美股 / 国际期货之外信息"最强的
一条证据链。

**Layer 4 影响系数（首次可识别）**：mideast_conflict 通过双门控，训练窗
（< 2026-05-15，163 个已结算事件）估计 beta_SC = 0.0599（t = 4.58）、
beta_AU = 0.0438（t = 4.10）：一个从"市场不信"到"发生"的满 surprise 事件，
对应 SC 次一交易日约 6% 的收益。russia_ukraine 通过门控但系数不显著
（t 约 0.4-0.6）——门控通过只保证"可检验"，不保证"存在"。

**H4（tension 对波动，探索性）**：narrative tension 对 SC 次日 |r_day| 的
系数为负（HAC t = -4.0，控制滞后波动）；AG 为正不显著。负号的一个可检验
解释：阶梯族失衡在**关注度低**的时段才会持续存在（套利者缺位），而低关注
恰与后续低波动同现。列为待复核现象，不作机制声称。

## 7. 局限与下一步

1. **ETF 控制集止于 2026-06-29**（美股库右端），7 月上旬的 OOS 行按缺控制
   剔除；CF 品种缺直连基准（BAL 已退市），控制集退化为 SPY + UUP。
2. **约 120 个训练观测**支撑不了全测量层的回归元数量；hazard / 分布特征的
   检验应当专项化（逐特征、逐主题）而非并入预测面板。
3. 影响系数为单次训练窗切分（滚动 cross-fitting 需更多事件），且只在
   mideast 一类上显著——跨事件类别的外推没有依据。
4. 事件类型标注未做人工复核轮；`admit_ts` 之外的市场条款编辑历史不可得。
5. 下一步的自然顺序：(a) 爬虫转入日常增量（`cursor.json` 已就位），样本
   每月自然增长约 20 个交易日；(b) 把 mideast beta 的事件研究扩展为
   surprise 分层（中段概率事件 vs 尾部）以直接检验"哪类事件携带增量"；
   (c) 波动率通道（H4 与 K5 的合并规格）值得独立成文。
