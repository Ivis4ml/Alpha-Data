# 下一阶段设计:补齐六条评审意见指出的短板

版本:v1.0(2026-07-22)。分支 `feat/cn-futures-polymarket`。
本设计经 36 个智能体分六题并行设计、每方案独立校验后综合而成;
文中全部 Bonferroni 门槛已用 scipy 实算复核。
标注"初测值"的统计量为设计阶段的一次性测算,实施时必须由脚本复算并写入
`key_numbers_v2.json`,不得引用本文数字作为结果。

## 0. 总原则(三条铁律)

1. **门槛只升不降**:任何扩展(品种、信号、评价方式)都会放大检验数,
   门槛随之上升。扩展的目的在于覆盖与信息量,不在于制造正结果。
2. **探索不冒充确认**:期货分钟样本止于 2026-07-13,未触碰样本当前不存在。
   在新数据交付前,125 天上算出的一切均为探索值,只出秩、不下结论;
   现行结论仍为诚实否定(纯 PM 798 检验 max|t| = 3.24 < 4.15)。
3. **gate 不缩分母**:映射分级、质量门控只能剪除候选,主族检验分母固定为
   预注册最大数,不因剪除而下调门槛。

冻结纪律:`freeze/manifest.json` 哈希锁定的七个脚本
(`v3_defense_build.py`、`v3_cross_section.py`、`v3_jump_factors.py`、
`v3_jump_inference.py`、`v3_c8_incremental.py`、`v3_prereg_tests.py`、
`v3_curve_family.py`)一律不改;新能力全部写 `v4_*` 新脚本,
新冻结项写入独立的 `freeze/manifest_v2.json`,不触碰旧账本。

## 2. 第一阶段(可立即实施,按依赖顺序)

### P1 事前映射强度表与品种参照表(回应意见 3、4;工作量:小)

一切品种扩展之前,先固化三样零期货数据的产物:

1. `docs/product_taxonomy.csv`:88 品种 → (中文名, 板块, 国际基准 ETF
   清单, 是否国际定价)。全部为合约规格与公开常识,属事前信息。
2. `data/polymarket/features/tier_registry.parquet`:每个(主题, 品种)对
   的映射强度,分 primary / secondary / exploratory 三档。强度 =
   主题对全球代理(如 mideast/oil 对 Brent、fed 对 USDCNH)的可预测性
   乘以品种对板块的教科书归属(板块表冻结)。金属与美联储链条缺长跨
   代理者标注 DATA_GAP、只用经济先验并注明证据弱。
3. `freeze/prereg_signs.json`:下一阶段每个候选因子的预期符号。

纪律:主族 Bonferroni 分母固定为预注册最大对数;未映射的品种归
exploratory 族,不进主族;`cn_registry_v3.parquet` 保持冻结,新映射写
`cn_registry_v4.parquet`。

脚本:`scripts/v4_mapping_strength.py`(生成 taxonomy 与 tier 表)、
`scripts/v4_freeze_mapping.py`(仿 `make_freeze_manifest.py` 生成
`manifest_v2.json`;注意绝不运行旧的 `make_freeze_manifest.py`,
它会覆盖旧冻结记录)。

验收:tier 表含全部 88 品种;manifest_v2 记录三产物哈希与冻结日期;
回归测试断言 `cn_registry_v3.parquet` 哈希未变。

### P2 涨跌停分类与双口径标签(回应意见 4d;工作量:中)

把 `locked = 1{high == low}` 细分两类:

- **真封板**:该分钟收盘价落在当日极值上(`close >= 当日 high` 或
  `close <= 当日 low`),价格被涨跌停约束,收益不可实现;
- **伪锁**:不在当日极值(含零成交分钟),只是清淡,不剔除、仅打标。

标签规则:入场分钟为真封板,该 bar 全部 `fwd_k` 置缺失;前向窗口
(t, t+k] 内任一分钟真封板,`fwd_k` 置缺失。同时保留未过滤版本作
稳健性对照,输出剔除比例表(`locked_impact.parquet`)量化选择效应。

初测:真封板占 locked 的比例 SC 约 66%,AG/M/AU 的 locked 几乎全部
落在极值(来自一到两个全天封板日,真实);处理前后纯 PM 极值 t 不变,
即该处理不制造正结果。

记账:`fwd_k_clean` 为主口径、与原 close 标签同族同计数,不新增检验、
不动门槛;须在 manifest_v2 预注册"clean 为主口径、raw 同报"。

脚本:`scripts/v4_signal_grid.py`(下一代评价引擎,内含 locked 分类、
双口径标签与剔除量化;逐字节复现现有 `signal_grid.parquet` 的 raw 口径
后才允许输出 clean 口径,作为回归测试)。

### P3 时序分位与成本净边界(回应意见 5、6;工作量:中)

对可分档的连续信号(约 26 个;准入为机械规则:滚动窗内最小唯一值数
与至少 60% 交易日两端极端档非空,预计剔除 K7/K8/K9 等),每品种、
每视界:

1. **分档**:按第 d 日之前 20 个交易日的非零值分位数定 10 档断点
   (严格历史断点,防前视),locked 真封板分钟不参与;
2. **多空组合**:`LS_k = 档10均值 - 档1均值`,日聚类 HAC t;
3. **单调性判据**:档序与档均值的 Spearman、对档序回归的斜率 t,
   两者同号且斜率 |t| 不低于 2;
4. **成本净边界**:`net_bp = 毛LS - 换手率 x 16bp`(成本常数沿用冻结
   的 COST_BP = 16),并报盈亏平衡毛价差。

三关全过才记"分位可交易"。初测:N2/N4 在 15 分钟视界的滚动断点
日聚类 t 小于 1,毛价差约 1bp,远低于盈亏平衡约 8bp,即分位透镜下
否定结论同样成立(该初测须复算)。

记账:注册 k=15、scope=all 为确认终点(约 125 个检验)并入主族 A:
1476 + 130 = 1606,门槛 4.146 升至 **4.165**(实算)。退化检验记
未通过、不移出分母。

脚本:`scripts/v3_quantile.py`(函数:`ts_quantile` / `net_edge` /
`monotonicity` / `infer`),配 `manifest_q.json` 登记注册终点清单。

### P4 主题内分散度矩族(回应意见 1、2;工作量:中)

把 N1 丢掉的横截面结构还原为每主题每分钟固定 6 个标量(固定维数,
不随市场数增长,不炸检验):

| 名称 | 定义 | 经济读法 |
|------|------|----------|
| disp | 成交额加权 sd(定向 Δℓ_m) | 主题内分歧度 |
| cancel | \|Σ w·Δℓ\| / Σ\|w·Δℓ\| | 合并的抵消存活率(1=全同向) |
| HHI | Σ(市场 usdc 份额)^2 | 活动集中度(一家独大 vs 普遍) |
| sign_ratio | 多数符号占比 | 方向一致性 |
| head_share | 头部市场贡献占比 | 信息由头部还是长尾驱动 |
| skew | 定向 Δℓ 的偏度 | 极端市场拉动 vs 普遍位移 |

实现要点:复用 `pm_minute_theme` 已暴露的市场分钟中间量(dl_m、w_m、
usdc),只改聚合方式,不重建 tape、不改冻结脚本;权重一律用时点化累计
usdc(禁用静态 usdc_win,防前视);当分钟活跃市场数为 1 时各列置缺失
(诚实减少检验数);disp 使用前须对 |N1| 与活跃市场数残差化或在报告中
披露该混淆。

记账:按全部非退化(品种, 主题)映射如实计数并入主族 A,约 +310 个
检验,1786 个,门槛升至 **4.189**(实算;与 P3 叠加时按实际总数重算)。

脚本:`scripts/v4_market_dispersion.py`,产物
`data/cn_futures/analysis/v4/dispersion_grid.parquet`,评价走 P2 的
`v4_signal_grid.py`。

### P5 品种扩展:5 到 8(回应意见 4a;工作量:中)

CF(棉花)、I(铁矿石)、IF(沪深 300)三品种在 `cn_registry_v3` 已有
事前映射(13/13/8 个市场)、分钟数据已在库,零数据成本、零事后选择。

硬性要求:

1. 新脚本 `scripts/v4_panel_build.py` 只读复用冻结脚本的分段、归一、
   信号定义逻辑(import 而非复制),并先对已冻结的 5 个 defense 面板
   **逐字节复现**通过回归测试后,才允许产出新面板;
2. IF 为纯日盘品种,依赖夜盘或隔夜累计的信号会退化,须实测各信号
   有效检验数并如实报告,不虚计分母;
3. 记账:8 品种强映射族约 2361 个适当检验,门槛升至 **4.252**(实算),
   比现行 4.15 更严;二线与探索品种分层独立记账,绝不并成 88 品种大池
   稀释(朴素并池 25977 个检验、门槛 4.761,失去分辨力)。

### P6 因子质量七关门控(回应意见 6;工作量:中)

把"后面对质量有要求"制度化为硬性准入,任一因子进确认层前逐关通过:

1. 事前经济假说与预期符号已登记(`prereg_signs.json` 有条目);
2. 频率覆盖可行(非零分钟占比、日均触发数达下限);
3. 正交后仍有增量(对 mom15_z / rv15_z / volu15_z / amt15_z 与闭市
   吸收代理残差化后,残差 IC 的 |t| 仍达族内门槛);
4. 分位单调(P3 判据);
5. 跨品种跨时段符号稳定(不低于 60% 品种一致、日夜盘不反号);
6. 成本后净收益非负;
7. 无前视自检(移位检验:信号后移一分钟,IC 应塌缩)。

门控本身不产生对外检验、不进任何族;其作用是缩小进入确认层 E 的
假设数,而确认必须在未触碰样本上一次性进行,绝不在同一 125 天样本上
先筛后判。

脚本:`scripts/next_factor_gate.py`,产物
`data/cn_futures/analysis/next/quality_scorecard.parquet`。

## 3. 第二阶段(需更重设计,列要点与前置条件)

1. **市场级信息保留**:头部/尾部分层聚合、每主题预注册旗舰市场、
   按生命周期(距结算远近)分层。红线:生命周期必须用 as-of
   `close_at`(事前已知),`resolved_at` 是未来信息只作事后删失;
   初测两者相差超过 7 天的市场占 40.7%,误用会制造伪 alpha。
2. **N1 重设计(enriched 面板)**:三条与 N1 正交的信道:概率水平
   条件化创新(软截断 / 分层 / Fisher 信息加权,救回被压平的近定局
   市场)、Kyle λ 残差(信息冲击与流动性冲击分离)、大额与散单分离
   (含 PIT 钱包技能加权;须先披露其日频检验为空的既有结果)。每个
   新度量只报对 N1 残差化后的增量 IC。
3. **映射系统化(88 品种)**:外部基准分级器在 pre-2026 长窗上用主题
   序列对国际 ETF 做 HAC 回归定强 / 中 / 弱档(初测:mideast 对 USO
   t = 2.64 成立;fed 链复现降息传导;russia_ukraine 被证伪)。
   前置:登记表市场的 first_ts 均在 2026 年,长窗主题序列须按关键词
   规则在全历史 daily_aligned 上重建。分级器为映射验证族 D,只做
   gate、不下结论。
4. **分钟横截面 top-bottom 组合**:每分钟跨品种按因子排序做多空,
   把品种维度收成每(因子, 时段)一条序列,是扩品种而不炸记账的
   唯一结构。截面族 C 预注册 12 因子 x 6 视界 x 3 时段 x 2 统计 =
   432 检验,门槛 3.855(实算);因估计量不同单独成族,但比主族松,
   故其命中只能作更弱主张、永不推翻主族否定。深夜时段国内仅少数
   品种交易、截面退化,如实标注。
5. **机制族因子库**:基于已解析的市场家族结构(价格阶梯 / 日期阶梯)
   构造 12 个"一句话讲清机理、事前定符号"的因子(阶梯隐含中位数、
   尾部溢价、近端 hazard、闭市吸收、分歧度预测波动),每个机制配一个
   可证伪的条件命题(如:若机制为信息传导时滞,效应应在流动性差的
   品种与时段更强)。

## 4. 检验总账(五族)

| 族 | 内容 | 规模与门槛 | 性质 |
|----|------|-----------|------|
| A 主族 | 分钟级逐品种 x 信号 x 视界(IC 与事件研究) | 现 1476 / 4.146;+分位确认 1606 / 4.165;+分散度约 1786 / 4.189;8 品种 2361 / 4.252(全部实算) | 确认性,FWER |
| B 纯 PM 子族 | A 的子集,单独报告口径 | 798 / 自身 4.003,但一律按 A 门槛判 | 报告透镜,非准入门 |
| C 截面组合族 | 分钟横截面多空(估计量不同) | 432 / 3.855,预注册后锁死 | 确认性但主张更弱,不得推翻 A |
| D 映射验证族 | pre-2026 外部 ETF 证据 | 约 30,BH-FDR q<0.10 | 纯 gate,不下结论 |
| E 确认层 | 未触碰样本一次性裁决 | 门控存活因子不超过 10 个,一因子一预约 | 唯一能产生"已验证 alpha"之处 |

诚实声明:期货分钟库止于 2026-07-13,E 层当前无样本可用;在新数据
交付前,本研究的对外结论保持为否定,所有新结果只作探索层记录。

## 5. 否决清单(设计校验阶段拒绝的方案)

1. 用 `resolved_at` 做生命周期分桶(未来信息,制造伪 alpha);
2. 旗舰市场单开小族取门槛 3.279(恰压在已证为噪声的 3.24 之上,
   变相放松门槛);
3. 任何形式的编造或压缩检验分母;
4. 新闻时戳 lift 检验(事件锚点即构造 N1 的市场本身,自指);
5. gate 剪除映射后回缩主族分母;
6. 波动 / 跨段标签冒充"同一信号的稳健性"逃避记账(它们是不同假设,
   各自预注册方向并计数)。

## 6. 实施顺序与验收


并以复算值为准。
